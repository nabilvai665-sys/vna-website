ভিডিও টিউটোরিয়াল

কোনো ভিডিওতে ক্লিক করলে এখানেই চলবে।

কোনো ভিডিও পাওয়া যায়নি। অন্য শব্দে খুঁজুন।

ব্রাউজার এক্সটেনশন চালু করুন

অ্যাপ ইনস্টলের পর ব্রাউজারে এক্সটেনশন চালু করলেই ডাউনলোড নিজে ধরা শুরু হবে।

  1. VnA Download Manager ইনস্টল করে অ্যাপ একবার খুলুন।
  2. Chrome বা Edge খুললে Enable Extension লেখা মেসেজ আসবে। সেটা Allow করুন।
  3. মেসেজ না এলে ব্রাউজারের স্টোর থেকে এক্সটেনশন নিজে যোগ করুন।
  4. এক্সটেনশন কাজ না করলে অ্যাপে Menu > Fix n Update > Repair Browser Extension চাপুন।
