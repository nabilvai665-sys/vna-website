ইনস্টলের আগে পড়ুন

Windows সতর্ক করলে ঘাবড়াবেন না

নতুন সফটওয়্যারে এটা খুব সাধারণ ঘটনা। একে বলে ফলস পজিটিভ (False Positive)। নিচের ধাপগুলো মেনে চললে ইনস্টল নির্বিঘ্নে হবে।

ফলস পজিটিভ মানে কী?

অ্যান্টিভাইরাস প্রতিটি ফাইলের ভেতরটা পুরো বুঝে না। সে ফাইলের আচরণ, কতজন নামিয়েছে আর পাবলিশার কতটা পরিচিত, এসব দেখে আন্দাজ করে। তাই নতুন ও কম পরিচিত সফটওয়্যারকে মাঝে মাঝে ভুল করে “সন্দেহজনক” ধরে ফেলে। সফটওয়্যারটি ঠিক থাকলেও এমন হয়, একেই ফলস পজিটিভ বলে।

VnA-কে কেন ধরতে পারে?

  • নতুন ফাইল: ডাউনলোড সংখ্যা কম, তাই Windows-এর কাছে এর রেপুটেশন এখনো তৈরি হয়নি।
  • ব্রাউজারের সাথে কাজ: ব্রাউজারের ডাউনলোড ধরতে একটি সহায়ক ফাইল (vna_host.exe) ও রেজিস্ট্রি এন্ট্রি লাগে। এই আচরণ কিছু ক্ষতিকর প্রোগ্রামের সাথে মেলে।
  • প্যাকেজিং পদ্ধতি: Python থেকে তৈরি এক্সিকিউটেবল ফাইলকে অনেক অ্যান্টিভাইরাস ভুল করে ধরে।
⚠️
কী ঘটতে পারে: ইনস্টলের পর অ্যান্টিভাইরাস vna_host.exe মুছে বা কোয়ারেন্টিনে পাঠাতে পারে। তখন অ্যাপে App Offline দেখায়। সমাধান: Windows Security-র Protection history থেকে ফাইলটি Restore করুন, তারপর অ্যাপের Settings থেকে Repair Extension চাপুন।
🛡️
নিরাপদ থাকতে: এই পদ্ধতি শুধু এই সাইট বা আমাদের অফিশিয়াল GitHub Releases থেকে নামানো ফাইলের জন্য। অন্য কোথাও থেকে পাওয়া ফাইলের জন্য সুরক্ষা বন্ধ করবেন না। সুরক্ষা বন্ধ থাকবে শুধু ইনস্টলের সময়টুকু, শেষে অবশ্যই আবার চালু করবেন।

    FAQ

    প্রশ্নোত্তর

    Windows বা অ্যান্টিভাইরাস সতর্ক করছে, এটা কি ভাইরাস?

    নতুন সফটওয়্যারে এমন সতর্কতা সাধারণ, একে ফলস পজিটিভ বলে। More info চেপে Run anyway চাপুন। ইনস্টল আটকে গেলে ইনস্টল গাইড অনুযায়ী অ্যান্টিভাইরাস সাময়িক বন্ধ রেখে ফোল্ডারটি Exclusions-এ যোগ করুন।

    ইনস্টলের পর App Offline দেখাচ্ছে, কী করব?

    অ্যান্টিভাইরাস সম্ভবত vna_host.exe মুছে ফেলেছে। Windows Security > Virus & threat protection > Protection history থেকে ফাইলটি Restore করুন, অ্যাপ ফোল্ডার Exclusions-এ যোগ করুন, তারপর অ্যাপের Settings থেকে Repair Extension চাপুন।

    Windows 10 আর Windows 11-এর ইনস্টলে পার্থক্য কী?

    Windows 11-এ Defender-এর পাশাপাশি SmartScreen (আর কিছু ভার্সনে Smart App Control) ইনস্টলার আটকাতে পারে। তাই Windows 11-এর গাইডে সেগুলোর ধাপও আছে।

    কোন Windows-এর জন্য?

    এই Setup 64-bit Windows-এর জন্য।

    ইনস্টল বা আপডেটে পারমিশন এরর এলে?

    আমাদের Telegram চ্যানেল থেকে Setup ফাইল নামিয়ে নতুন করে ইনস্টল করুন।

    অ্যাপ বন্ধ থাকলে ব্রাউজারের ডাউনলোড কী হবে?

    এক্সটেনশন তখন ব্রাউজারের নিজস্ব ডাউনলোড আবার চালু করে দেয়, কিছু হারাবে না।

    লিংকের মেয়াদ শেষ হয়ে গেলে?

    ডাউনলোডে রাইট-ক্লিক করে Refresh Download Address চাপুন। পেজ খুলে ভিডিও চালালে অ্যাপ নতুন লিংক ধরে বাকিটা চালিয়ে নেয়।

    ফ্রি ট্রায়াল কত দিনের?

    ৩ দিনের। এরপর Premium Key দিয়ে অ্যাপ Activate করতে হয়।

    সমস্যা হলে কোথায় জানাব?

    নিচের Telegram, ফেসবুক পেজ বা YouTube চ্যানেলে জানান।

    ডাউনলোডের আগে ১ মিনিট ⚠️

    নতুন সফটওয়্যার বলে Windows Defender বা অ্যান্টিভাইরাস একে ভুল করে (ফলস পজিটিভ) আটকে দিতে পারে। এটা সাধারণ ঘটনা।

    1. ইনস্টলের সময় অ্যান্টিভাইরাস সাময়িক বন্ধ রাখুন।
    2. ইনস্টলারের শেষ পেজে Finish চাপার আগে থামুন, অ্যাপ ফোল্ডার Exclusions-এ যোগ করুন।
    3. অ্যান্টিভাইরাস আবার চালু করে তারপর Finish চাপুন।
